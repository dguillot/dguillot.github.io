About

What this site is

It Used To Say tracks dialogue that changed after a movie left theaters: replaced words, muted swears, and deleted lines. It is not a complete cut-comparison database. For scene-by-scene runtime diffs, see specialist sites such as Movie-Censorship.com.

The first catalog is a starter set of well-known examples so the layout has real content. Each entry should name the movie, the speaker, the original line, what replaced it (or that it was removed), the version type, and a source.

What we do not do

  • Host movie files or clips.
  • Claim a streaming copy is “wrong” as a legal matter — only that it differs.
  • Reprint slurs when describing a deletion. Those entries describe the cut instead.
